# Life RPG - Frontend

React + Vite frontend for the Life RPG gamification app.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The frontend dev server will start at `http://localhost:5173`. API requests to `/api` are automatically proxied to the backend at `http://localhost:8000`.
